# ₿ Bitcoin Academy

An **interactive, engaging, and visually stunning** web application designed to teach users about Bitcoin and blockchain technology through immersive learning experiences.

## ✨ Features

### 🎓 Educational Modules

Learn Bitcoin fundamentals through 6 comprehensive modules:

- **What is Bitcoin?** - Understand the revolutionary digital currency
- **The Blockchain** - Explore distributed ledger technology
- **Bitcoin Mining** - Learn how new bitcoins are created
- **Transactions** - See how value is transferred peer-to-peer
- **Bitcoin Wallets** - Discover secure storage solutions
- **The Future** - Explore Bitcoin's role in the global economy

### 🎮 Interactive Demonstrations

Experience Bitcoin technology through hands-on simulations:

- **Blockchain Visualization** - See how blocks are linked together in real-time
- **Mining Simulator** - Experience the proof-of-work process
- **Transaction Demo** - Watch transactions get confirmed on the network

### 🎨 Stunning Design

- Smooth animations powered by Framer Motion
- Beautiful gradient effects and glassmorphism
- Responsive design that works on all devices
- Dark theme with Bitcoin-orange accents
- Floating elements and engaging micro-interactions

## 🚀 Quick Start

### Prerequisites

- Node.js 18+ and npm

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

The app will be available at `http://localhost:5173`

## 🛠️ Tech Stack

- **Framework**: React 19.2 with TypeScript
- **Build Tool**: Vite 7.2
- **Styling**: Tailwind CSS 3.4
- **Animations**: Framer Motion 11.0
- **Icons**: Lucide React
- **Language**: TypeScript 5.9
